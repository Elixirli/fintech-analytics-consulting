# Startup Financial Analytics Sample

## Objective
Create a reusable financial analytics template for an early-stage business using synthetic data.

## Planned Analysis
- Revenue and expense trends
- Gross margin
- Operating burn
- Cash runway
- KPI summary
- Simple forecast structure

## Evidence
The Excel model in this folder is a reusable work product for future consulting engagements.

## Data Note
All sample data are synthetic and are not associated with a real client.
