# Financial Data Validation Checklist

- [ ] Confirm reporting period and data source
- [ ] Check for missing required fields
- [ ] Check for duplicate records
- [ ] Confirm dates are valid and consistently formatted
- [ ] Confirm units and currency are consistent
- [ ] Review sign conventions for revenue, expense, assets, and liabilities
- [ ] Reconcile totals to source reports where applicable
- [ ] Review unusual or extreme values
- [ ] Document adjustments and assumptions
- [ ] Preserve source-to-output traceability
