# Financial Data Validation Sample

## Objective
Create a reusable checklist for reviewing financial datasets before modeling or reporting.

## Validation Areas
- Missing values
- Duplicate records
- Date consistency
- Sign and unit consistency
- Balance / reconciliation checks
- Outlier review
- Source-to-output traceability

## Data Note
This sample is intended as a reusable consulting work product and does not contain client-confidential data.
